## Issue #1（VS 连局域网需 HTTPS）处理

- **根因**：① Hub 默认只绑 `127.0.0.1`（安全默认，避免无鉴权进程把上游 Key 暴露到局域网）；② VS / VS Code 的 Copilot 对**非 localhost 地址强制要求 HTTPS**，而 Hub 此前只提供明文 HTTP → VS 直接拒绝。
- **回复 Issue #1**：通过 GitHub REST API（`api.github.com`，用 git credential store 里的 Fine-grained PAT）在 Issue #1 下发布评论（HTTP 201），给出 Caddy 反代 + 自签证书信任的临时方案，并预告原生 HTTPS 修复。
- **实现原生 HTTPS（正式修复）**：
  - `Config/HubSettings.cs` 新增 `HttpsPort`（>0 启用）、`Certificate`（PFX 路径，相对 settings.json 目录或绝对）、`CertPassword`。
  - `Http/OllamaHttpServer.cs`：新增独立 TLS 监听——`HttpServer.Certificate = new X509Certificate2(pfx, pw, Exportable)`，固定绑 `0.0.0.0:<HttpsPort>`，复用 `BindRoutes`；扩展 `StopListener`/`OnConfigChanged`（`ReconcileHttps` 对账端口与证书变更，热重载无需重启）；`/api/status` 增加 `httpsPort`/`httpsEnabled`。
  - 反射确认 `NewLife.Core.HttpServer` 原生支持 TLS（`Certificate`/`SslProtocol`/`SslStream` 成员），故无第三方依赖。
  - e2e 验证：发布到 `tools/https_test`，用 `tools/certgen`（dotnet 小程序）生成自签 PFX，运行后 `curl -k https://127.0.0.1:11445/api/version` 与 `/api/status`（返回 `httpsEnabled:true`）均成功。
  - 文档：`docs/configuration.md` 增「HTTPS（局域网 / VS Copilot）」章节；`docs/faq.md` 增对应问答。
- 构建 0 错误；`self-test` 168/0 全绿。

## 配置拆分重构（双监听节点独立化，已完成实现）
- **用户最终决策**：**不保留旧字段兼容**，直接以新结构为准（覆盖上面的"向后兼容"计划）。
- **`HubSettings` 重构**：
  - 删除顶层旧字段 `Url`/`Host`/`Port`/`HttpsPort`/`Certificate`/`CertPassword`。
  - 新增 `ListenerOptions` 基类（`Enabled`/`Host`/`Port`/`Scheme`/`UseTls`/`Url`）+ 派生 `LocalListener`(默认 enabled true/127.0.0.1/11434/useTls false) 与 `HttpsListener`(默认 enabled false/0.0.0.0/11435/useTls true + `Certificate`/`CertPassword`)。
  - `HubSettings` 暴露 `Local`/`LanHttps` 属性；`Normalize()` 改为归一化两个子对象（派生 `Local.Url = http://host:port`、`LanHttps.Url = https://host:port`）；`Load`/`Save` 保留（JSON 直接映射新结构）。
- **`OllamaHttpServer` 重构**：
  - 字段 `_server`/`_boundUrl`/`_httpsServer`/`_httpsBoundPort`/`_httpsCertPath`/`ListenUrl` → `_localServer`/`_httpsServer`/`_localBound`/`_httpsBound`；`ListenUrl` 公开属性删除（改由 `HandleStatus` 输出 `listeners[]`）。
  - `Start()` 先 `Normalize()`，再按 `Local.Enabled`/`LanHttps.Enabled` 分别 `StartListenerInner(cfg)`；通用方法按 `cfg.UseTls` 决定 HTTP/HTTPS（`HttpServer.Certificate = X509Certificate2`，证书缺失则告警跳过该监听）。
  - `Stop()` 同时停两个；`OnConfigChanged` 统一调 `ReconcileListeners()`（逐监听对账 enabled/地址/证书，缺失/失败回退原状态，无需重启）；`HandleStatus` 输出 `listeners[]`（每项 `name`/`scheme`/`enabled`/`url`/`host`/`port`/`bound`）+ 移除 `listenUrl`/`httpsPort`/`httpsEnabled`。
- **`ProviderPresets` 默认构造**：`new HubSettings { Host=.., Port=.. }` → 无参 `new HubSettings()`（默认已含 local 监听）。
- **`HubAgentService`/`SelfTest` 同步**：启动日志去掉 `ListenUrl`；`CheckSettingsSchema` 改测新结构（默认 Local 11434 + 显式两节点往返保留供应商/模型）→ **新增 3 项 schema 测试**。
- **`AdminPanel.html`**：状态卡片改为分别展示 `local`/`lanHttps` 两个监听（启用状态 + URL + bound 标记）。
- **文档**：`docs/configuration.md` 改「本地与局域网监听（双节点）」章节（新结构示例）+ 热重载段去掉 `listenUrl`/`host`/`port` 旧描述 + `/api/status` 示例改 `listeners[]`；`docs/faq.md` 的 VS Copilot 问答同步；`examples/*.json` 顶部 `host`/`port` → `local` 节点（6 个 11434 + ollama-passthrough 11435，CRLF 保留，仍合法 JSON）。
