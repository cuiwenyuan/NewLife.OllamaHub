- `github.com:443` 被 SNI 阻断（`Recv failure`/`Could not connect`），但 `api.github.com` 可达（200）。常规 `git push` 失败，改走 **Git Data API**（`api.github.com`）推送并打 tag：
  1. 取 PAT：`git credential fill`（protocol=https/host=github.com/username=cuiwenyuan）→ password。
  2. 读 base=`12ddd6d`（原 remote main，已知 SHA）、其 tree；对 11 改文件逐个 `POST /git/blobs`（content base64/encoding=base64）→ 建 `POST /git/trees`（base_tree + 11 entries）→ 建 `POST /git/commits`（message/tree/parents=base + **显式 author/committer/date 与本地 commit 完全一致**）→ 得 SHA 精确等于本地 `ef950fc`（tree 也一致）。

  4. `DELETE /git/refs/tags/v1.3.0`（如已存在，204 无 body 需容错）→ `POST /git/refs` 建 `refs/tags/v1.3.0` → ef950fc。
