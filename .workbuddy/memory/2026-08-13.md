# 2026-08-13

## 修复配置向导直接取消的 bug
- 问题：菜单用 `Console.ReadKey` 读取 `c` 后，用户按 Enter 的回车符残留在输入缓冲区，`PickPresetIds` 里的 `Console.ReadLine()` 立即读到空行，导致向导提示"未输入任何供应商 id，已取消"。
- 修复：`HubAgentService.PickPresetIds` 在 `ReadLine()` 前先 `while (Console.KeyAvailable) Console.ReadKey(intercept: true);` 清空缓冲区。
- 验证：`dotnet build` 0 错误；`self-test` 211/0；发布到 `publish-test-new` 后再次 self-test 211/0。

## DeepSeek/VS 连接 192.168.31.51:11435 超时排查

## 配置向导提示不明确 + 残留回车 bug 二次修复
- 根因：`ConfigureWizard` 首次配置分支直接调用 `PickPresetIds()`，没有任何输入提示，用户只看到光标闪烁；且 `ReadKey` 后的回车残留会跳过后续 API Key 输入。
- 修复：
  - `PickPresetIds` 增加 `prompt` 参数，清缓冲后打印该提示。
  - 新增 `ClearInputBuffer()` 辅助方法，统一在 `ReadKey` 后调用。
  - `ConfigureWizard` 首次配置时打印明确规则、列出可选供应商；覆盖/沿用分支也加清晰引导。
- 验证：`dotnet build` 0 错误；`self-test` 211/0；已重新发布到 `publish-test`。等待用户验证交互。
