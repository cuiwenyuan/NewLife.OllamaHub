## 对标 iqmeta/copilot-ollama-multi-provider-ai-proxy（现名 ai-proxy-hub）
- 技术栈 .NET 10 + ASP.NET Core 最小 API；9 provider（无 anthropic/responses）；零拷贝 SSE 透传、推理缓存、force-mode 参数覆盖、X-Proxy-* 诊断头、可选 Bearer 鉴权(PROXY_API_KEY)；仅本地 HTTP 无证书/TLS。
- 我方优势：11 provider（含 anthropic/gemini/google/responses 上游适配）、三监听+证书+VS HTTPS 直连、Windows 单文件服务化、多模态透传更全。
- 我方差距/可借鉴：inbound 无鉴权（memory 已记"暴露局域网=Key 暴露"）、无诊断响应头；对标零拷贝 SSE 吞吐更高（我方翻译累积保真优先）。可加 Bearer 鉴权 + X-Hub-* 头。
